# Where'd It Go — учёт личных расходов

Сайт: **https://olzxwq.github.io/whered-it-go/**

Личный сайт для учёта расходов. Работает на iPhone, iPad и ноутбуке, данные синхронизируются через Яндекс Диск. Сервера и базы данных нет: всё хранится на самих устройствах, а общий файл лежит в папке приложения на Диске.

## Что умеет

- добавление расхода за пару касаний: сумма, категория, источник денег, карта, название с подсказками, дата;
- главный экран: итог за месяц, сравнение со всем прошлым месяцем, разбивка по источникам, последние расходы;
- список расходов за месяц с фильтрами, поиском, исправлением и удалением;
- статистика: разбивка по категориям, источникам и названиям (диаграмма и таблица), траты по дням, фильтр по карте;
- профиль: категории, источники, карты, синхронизация, экспорт в CSV, тема;
- светлая и тёмная тема, значок на главном экране, работа без интернета.

## Как это устроено

| Часть | Технология |
|---|---|
| Интерфейс | React + TypeScript, сборка — Vite |
| Хранение на устройстве | IndexedDB (база в браузере) через библиотеку Dexie |
| Синхронизация | файл `data.json` в папке «Приложения/Where'd It Go» на Яндекс Диске |
| Значок и офлайн | PWA (vite-plugin-pwa) |
| Размещение | GitHub Pages, выкладка через GitHub Actions |
| Тесты | Vitest |

Подробный план и все принятые решения — в [PLAN.md](PLAN.md).

### Как работает синхронизация

У каждой записи есть `updatedAt` (время изменения). Удалённая запись не стирается, а помечается `deleted: true`. При синхронизации сайт скачивает `data.json`, для каждой записи оставляет более свежую версию, сохраняет результат у себя и загружает обратно. Каждое устройство хранит полную копию, поэтому без интернета всё работает, а изменения уходят позже.

Синхронизация запускается при открытии сайта, при возвращении в приложение, при появлении интернета, через 3 секунды после изменения и кнопкой в профиле.

## Как запустить у себя на компьютере

Нужен **Node.js** (LTS-версия, https://nodejs.org) и **Git**.

1. Скачать зависимости (один раз и после изменения `package.json`):
   ```bash
   npm install
   ```
2. Запустить сайт:
   ```bash
   npm run dev
   ```
   Сайт откроется на http://localhost:5173. При изменении кода страница обновляется сама.
3. Остановить: `Ctrl + C` в окне терминала.

**Проверка на iPhone или iPad до публикации:** телефон и ноутбук в одной Wi-Fi сети. После `npm run dev` в терминале будет строка `Network: http://192.168.…:5173` — открыть этот адрес в Safari. Если не открывается, разрешить Node.js доступ в частных сетях в брандмауэре Windows. Вход через Яндекс по такому адресу работать не будет (он не указан в настройках приложения Яндекса), для синхронизации используйте localhost или опубликованный сайт.

## Как выкладывать обновления

Сайт обновляется автоматически после каждой отправки кода на GitHub в ветку `main`.

1. Сохранить изменения в git:
   ```bash
   git add -A
   ```
   ```bash
   git commit -m "Что изменилось"
   ```
2. Отправить на GitHub:
   ```bash
   git push
   ```
3. GitHub сам запустит тесты, соберёт сайт и выложит его. Ход выкладки — на вкладке **Actions** репозитория: https://github.com/olzxwq/whered-it-go/actions. Обычно это 1–2 минуты. Если тесты не прошли, сайт не обновится, а у запуска будет красный крестик.
4. На iPhone и iPad новая версия появится после того, как приложение полностью закрыть и открыть снова (иногда нужно два раза).

## Настройки внешних сервисов

**GitHub Pages:** репозиторий → Settings → Pages → Source: **GitHub Actions**.

**Приложение Яндекса** (https://oauth.yandex.ru → «Where'd It Go»):
- тип: «Для авторизации пользователей»;
- Redirect URI: `https://olzxwq.github.io/whered-it-go/` и `http://localhost:5173/`;
- доступ: только «Доступ к папке приложения на Диске» (`cloud_api:disk.app_folder`);
- ClientID записан в `src/sync/yandexDisk.ts` — он не секретный. Client secret сайту не нужен и в код не попадает.

Запасной вход «Войти по коду» в профиле работает, только если в Redirect URI приложения добавлен ещё адрес `https://oauth.yandex.ru/verification_code`.

Если сайт переедет на другой адрес, этот адрес нужно добавить в Redirect URI.

## Резервная копия

- Все данные лежат на Яндекс Диске: «Приложения» → «Where'd It Go» → `data.json`.
- В профиле есть «Скачать CSV» — все расходы одним файлом для Excel (разделитель `;`, кодировка UTF-8 с BOM).

## Если что-то не работает

| Проблема | Что делать |
|---|---|
| Красная надпись в карточке «Синхронизация» | В скобках написано, на каком шаге ошибка. Нажать «Синхронизировать» ещё раз; если не помогает — «Отключить» и подключить Диск заново |
| «Доступ к Диску больше не действует» | Подключить Диск заново (доступ выдаётся примерно на год) |
| На iPhone не появилось обновление сайта | Полностью закрыть приложение и открыть снова, при необходимости дважды |
| `npm run build` падает с ошибкой `Unable to write the service worker file … is not valid JSON` | В папке `C:\Users\<имя>\AppData\Local\Temp\` лежит посторонний файл `package.json` — удалить его. На GitHub сборка от этого не зависит |
| Сайт не открывается на телефоне по Wi-Fi | Проверить, что телефон в той же сети, и разрешить Node.js в брандмауэре Windows |
